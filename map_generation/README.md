# Map-generation source

`WFCUnity3DEnv.py` and `pcgworker/` are the retained WFC/PCG source components used to generate candidate maps. Generated caches, Unity build products, compiled extensions, and unrelated training artifacts are intentionally excluded.

The nested `pcgworker/LICENSE` applies to that retained component. The repository MIT license applies to code without a more specific retained notice.

These sources document generation, not the complete historical selection orchestration. Frozen selection metadata is in `data/map_generation/`.
